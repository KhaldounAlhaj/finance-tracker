# Finance v10.3 QA Corrections — Design Specification

Date: 2026-08-15  
Status: Owner approved

## Objective

Correct the post-v10.2 QA findings without changing stored data, migrations, reminder semantics, budget definitions or the offline architecture.

## Accounting

- `balance_adjustment` changes only the selected debt balance. It contributes zero spending, zero liquidity movement, zero income and zero goal movement.
- One shared entry classifier determines whether an entry is consumption spending, goal movement, debt payment, income or reconciliation and normalizes its payment source.
- Legacy `expense` entries in goal categories count as goal movement in both summaries and drill-throughs.
- A legacy goal entry funded by a configured credit card changes the card balance but does not reduce current liquidity until the card is paid.
- Debt and goal totals remain outside consumption spending.

## Closed months

The closed-month Overview retains its historical banner and concise actual rows, then adds:

- Cash left now for that selected month.
- After upcoming commitments for that selected month.
- Spent this month with source rows.
- Debt payments.
- Moved to goals.

Every row drills into Log using the selected historical month. Current debt and goal balances are not presented as historical snapshots.

## Filters and presentation

- Changing the Overview month updates any active activity drill to the new selected month.
- Opening a drill clears contradictory free-form Log controls; users may apply new filters afterward.
- An empty filtered result says no matching transactions, not no entries exist.
- A negative source total displays a real minus sign and remains visually identifiable as a net refund.
- Source rows and drill contents must reconcile under the same classifier.

## Compatibility and release

- No model-version, storage-key or migration change.
- No external dependency or network call.
- Release cache: `finance-v10.3`.
- All existing tests remain green and regression tests cover every corrected QA finding.
